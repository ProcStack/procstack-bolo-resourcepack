# Bolo - Sword + Axe Hybrid

A Minecraft data pack & resource pack by **ProcStack** introducing the **Bolo**, a hybrid tool and weapon combining sword and axe capabilities.

## Features

- **Bolo Types**:
  - Wood, Copper, Stone, Iron, Gold, Diamond, Netherite
- 1 Stick (Lower Left) & 1 Material (Upper Right); 2x2
- Custom crafting and smithing recipes
- Integrates sword and axe gameplay mechanics

Slightly weaker but faster than a sword
<br/>Slightly slower chopping wood than an axe
<br/>&nbsp;&nbsp; Balanced to work with Swords & Axes in game

Bug - Smithing recipe outputs Diamond Bolo, use a netherite ingot in the crafting table like any other material type.
